# VentureVerse 2026 — EDC Event Landing Page

A responsive, vanilla HTML/CSS/JavaScript landing page with a soft neutral palette and CSS-built 2D student illustrations (no photography required).

## Run locally

1. Extract the project folder.
2. Open `index.html` in a modern browser. For best local development, use VS Code's Live Server extension.

## Included
- Responsive navigation and mobile menu
- Hero section with event details and a live countdown
- About and event highlight cards
- Agenda timeline
- Fictional illustrated speaker profiles
- Client-side registration form validation and demo confirmation
- Reduced-motion and reduced-transparency fallbacks

## Notes
- The venue is the fictional placeholder from the brief.
- Speaker names and organisations are fictional.
- The registration form is a front-end demo. It does not send or store personal information.
- The countdown uses 12 November 2026, 10:00 AM India Standard Time.


## Official logos
The `assets/` folder contains optimized transparent EDC logos for light and dark themes and the JSS University emblem. The theme toggle switches the EDC mark automatically. Keep the `assets/` folder alongside `index.html`, `styles.css`, and `script.js` when hosting the site.
